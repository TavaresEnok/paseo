# Origem do código distribuído

Este repositório reúne código próprio da instalação e uma cópia dos artefatos distribuídos dos pacotes `@getpaseo/cli` e `@getpaseo/server` 0.13.2 efetivamente instalados no NexoISP. Os artefatos estão em `installed-paseo/` e mantêm seus metadados `package.json` e os avisos existentes nos arquivos.

O nome e a autoria do produto Paseo pertencem aos respectivos autores. Não foi atribuída uma nova licença aos arquivos de terceiros ou ao conjunto deste snapshot. Consulte os termos dos projetos/pacotes de origem antes de redistribuir ou relicenciar qualquer parte.

O JavaScript distribuído da interface web está incluído para comparação com a instalação. Arquivos de compressão equivalentes, modelos binários de voz, dependências npm, executáveis dos CLIs e caches foram omitidos. A fonte original TypeScript/React e o histórico Git upstream não foram reconstruídos a partir desses artefatos.
